# 📋 Task Manager App

A full-stack task management web application built with React, Node.js, Express & MongoDB.

## 🚀 Live Demo
Coming soon...

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Auth:** JWT Authentication

## ✨ Features
- ✅ User Register & Login
- ✅ Create, Update, Delete Tasks
- ✅ Priority Levels (High/Medium/Low)
- ✅ Search & Filter Tasks
- ✅ Progress Bar
- ✅ Responsive Design
